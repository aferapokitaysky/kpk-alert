# Керування звуковими сценаріями

Панель керування сценаріями розміщена в автономному модулі `features/sound-presets`. Вона використовує наявний API й не завантажує аудіофайли: файлова доставка сценаріїв належить окремому процесу.

## Доступ

Список і зміни доступні глобальному адміністратору. Клієнт приховує форму для інших ролей, але остаточне рішення про доступ завжди приймає сервер. Усі запити виконуються з `cache: no-store` і тією самою cookie-сесією.

## API-контракт

| Метод і шлях                             | Призначення                                                 |
| ---------------------------------------- | ----------------------------------------------------------- |
| `GET /api/v1/presets/manage`             | Отримати всі сценарії, зокрема чернетки                     |
| `POST /api/v1/presets`                   | Створити неопубліковану чернетку                            |
| `PUT /api/v1/presets/{code}`             | Змінити назву, пріоритет і SHA-256 неопублікованої чернетки |
| `PUT /api/v1/presets/{code}/publication` | Опублікувати сценарій або зняти його публікацію             |

Запити `POST` і `PUT` передають JSON та `X-CSRF-TOKEN`, отриманий з `/api/v1/auth/csrf-token`. Усі відповіді API перевіряються перед використанням.

Поля сценарію:

- `code` — 1–80 символів: малі латинські літери, цифри та `_`; після створення незмінний;
- `name` — назва довжиною 1–160 символів;
- `priority` — ціле число; менше значення розташовується вище;
- `manifestHash` — 64 шістнадцяткові символи SHA-256;
- `isPublished` — стан публікації, який змінюється окремою дією.

Опубліковані метадані сервер не дозволяє редагувати. Спочатку адміністратор знімає публікацію, після чого оновлює чернетку та публікує її знову. Відповідь `409` означає конфлікт стану або паралельну зміну; панель показує пояснення й дає оновити список.

## Перевірки

UI-тести перевіряють розмежування ролей, стани опублікованих сценаріїв, створення та редагування чернетки, CSRF-заголовок, кодування параметра шляху, конфлікт і завершення сесії.
