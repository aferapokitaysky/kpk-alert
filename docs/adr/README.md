# Реєстр архітектурних рішень

Архітектурне рішення (ADR) коротко фіксує контекст, варіанти, обране рішення та його наслідки. Змінювати прийняте рішення потрібно новим ADR зі станом `Superseded`, а не переписуванням історії.

Формат: `NNNN-коротка-назва.md`. Стани: `Proposed`, `Accepted`, `Rejected`, `Superseded`.
