# Узгодження інтерфейсу з Academica

Цей документ фіксує спостережувані рішення інтерфейсу журналу в локальному репозиторії Academica. Мета — зробити Alert частиною того самого цифрового середовища закладу, а не створити окрему візуальну мову.

## Що вже є в журналі

- Основний інтерфейс побудований на Razor Layout із React-компонентами для окремих сторінок та острівців взаємодії.
- Спільні стилі знаходяться в `ClientApp/src/styles/app.css`; пакет збирається Webpack у `wwwroot/dist`.
- Є компонент нативного HTML `<select>` з узгодженою стрілкою: `ClientApp/src/components/Select.tsx`.
- Логотип завантажується з налаштувань закладу, а за відсутності власного зображення використовується `/images/kpk-logo.png`.
- Основна палітра — синій бренду Кременчуцького педагогічного коледжу, жовтий акцент і нейтральна шкала slate.
- Шрифт — Inter; базовий текст 14 px.
- Ліва панель має ширину 256 px, згортаний стан 72 px, верхня панель — 64 px. На ширині до 820 px меню стає виїзною панеллю.
- Поля форм мають світле тло, тонку сіру рамку, радіус 8 px і синє кільце фокуса.
- Кнопки мають висоту близько 36 px; основна дія використовує синій колір і видимий стан клавіатурного фокуса.
- Поверхні карток білі з тонкою рамкою, радіусом 10 px і стриманою тінню.

## Брендові токени

У журналі визначені CSS-змінні, які треба використати як вихідну палітру Alert:

| Призначення        | Токен / колір                |
| ------------------ | ---------------------------- |
| Основний синій     | `--kpk-blue: #0e62d6`        |
| Наведення на синій | `--kpk-blue-hover: #0a52b8`  |
| Темний синій       | `--kpk-blue-strong: #083f8e` |
| М’який синій       | `--kpk-blue-50: #e8f0fc`     |
| Жовтий акцент      | `--kpk-yellow: #fab005`      |
| Тло сторінки       | `#f8fafc`                    |
| Поверхня           | `#ffffff`                    |
| Основний текст     | `#0f172a`                    |
| Межі               | `#e2e8f0` / `#cbd5e1`        |

Для небезпечних дій застосовують семантичний червоний колір. Жовтий не слід використовувати як колір тексту на білому тлі без перевірки контрастності.

## Вибіркові поля

Перевага надається нативному `<select>` з компонентом і правилами, аналогічними Academica:

- клас `form-control form-control-sm`;
- мінімальна ширина 132 px у компактних панелях;
- власна SVG-стрілка, але нативна поведінка клавіатури й читачів екрана;
- фокус із синьою рамкою та кільцем `--brand-ring`;
- на вузькому екрані ширина поля може заповнювати контейнер.

Пошуковий мультивибір додають лише для сценарію, де справді треба обирати багато корпусів або файлів. Він має зберігати підказки клавіатури, доступну назву, стан фокуса й екранного читача.

## Логотип і графічні ресурси

Не створювати окрему версію логотипа з довільним розміром. Alert використовує копію затвердженого статичного ресурсу `src/Academica.Web/wwwroot/images/kpk-logo.png` у `src/Watcher.Api/wwwroot/images/kpk-logo.png`; пропорції зберігаються через `object-fit: contain`. Клієнт завантажує файл із власного ресурсу Watcher і не залежить від доступності Academica.

Не підключати стилі журналу напряму через браузер або CDN: ізольований Watcher має власний збірковий пакет і не повинен залежати від доступності журналу. Спільні токени оформити як версіонований пакет лише тоді, коли обидва проєкти можуть його підтримувати.

## Правила для панелі Alert

- Весь видимий текст — українською: назви сторінок, поля, кнопки, підтвердження, порожні стани, помилки й повідомлення про стан з’єднання.
- Використовувати ту саму навігаційну геометрію, шрифт, кольори, форми полів, радіуси, відступи та фокус, що й журнал.
- Екстрені кнопки мають спеціальну композицію й сильний колірний сигнал, але загальна панель лишається в стилі Academica.
- Не використовувати емодзі як піктограми основних дій; для дій застосовувати послідовні SVG-іконки.
- Стани мережі й обладнання показувати текстом та піктограмою, а не лише кольором.
- Підтвердження запуску має чітко називати дію й обрану локацію.
- Доступність сервера береться з `/api/v1/health/ready`, що перевіряє готовність залежностей; це не є підтвердженням стану вузлів. Якщо джерела стану пристроїв немає, показувати це явно.
- Для списків відображати завантаження, відсутність сесії, відмову в доступі, порожній результат і помилку окремо.
- Перевірити ширини 360 px, 768 px, 1280 px і широке desktop-вікно; основні кнопки запуску доступні великим пальцем на телефоні.
- Підтримувати клавіатуру, видимий фокус, контраст WCAG AA для звичайного тексту та `prefers-reduced-motion`.

## Точки для повторного використання

Перед першою UI-фічею в Academica перевірити актуальні файли:

- `src/Academica.Web/ClientApp/src/styles/app.css` — CSS-змінні й базові компоненти;
- `src/Academica.Web/ClientApp/src/components/Select.tsx` — нативний узгоджений список;
- `src/Academica.Web/ClientApp/src/components/Button.tsx` — приклад варіантів кнопки;
- `src/Academica.Web/Views/Shared/_Layout.cshtml` — структура навігації, заголовка й логотипа;
- `src/Academica.Web/wwwroot/images/kpk-logo.png` — стандартний логотип.

Шляхи наведені від кореня репозиторію `журнал`. Перед перенесенням токенів звірити їх із поточною версією гілки Academica, оскільки цей проєкт змінюється окремо.

## Поточна композиція Alert

- Пульт має дві робочі колонки: корпуси й сценарії. На вузькому екрані вони переходять у вертикальний порядок: спочатку вибір цілі, потім дія.
- Статус джерел тривоги розміщений окремо перед вибором корпусів. Він показує рівень, область даних, джерело й актуальність; цей блок не підмінює стан вузлів і не запускає команду.
- Після оновлення вкладки пульт відновлює останню команду через захищений GET. У `sessionStorage` зберігається тільки її UUID; недоступна команда прибирається без розкриття її існування, а вихід очищує посилання.
- Верхня панель використовує темний синій для навігаційного контрасту; основні дії лишаються в синьому кольорі, жовтий — тільки для позначення уваги.
- Типографіка використовує одну шкалу: 12 px для метаданих, 14 px для основного тексту, 16 px для полів, 18 px для заголовків секцій та 24–32 px для заголовка сторінки. Міжряддя — 1.4 для коротких підписів, 1.5 для тексту й 1.25 для заголовків.
- Фільтри журналу трактують введені дату й час як `Europe/Kyiv` незалежно від часового поясу пристрою; неіснуючий час під час весняного переходу та повторний час під час осіннього переходу потрібно відхиляти з поясненням. До API передавати лише однозначний UTC ISO-час.
- Активний пункт меню повторює патерн Academica: м’яке синє тло й вузька жовта смуга зліва.
- Посилання входу використовують кольоровий знак Google з екранним приховуванням декоративної піктограми; у мобільному верхньому рядку лишається логотип КГТА.
- Мінімальна висота інтерактивних цілей — 44 px. Поля мають розмір тексту 16 px, щоб iOS не збільшував сторінку при фокусі.
- На телефоні логотип лишається у верхній панелі, а підтвердження відкривається нижньою карткою з основною кнопкою внизу та прокруткою довгого вмісту.
- Мобільний drawer і нижній край сторінки враховують `safe-area-inset-*`; viewport налаштовано з `viewport-fit=cover`.
- Перехідні ефекти вимикаються через `prefers-reduced-motion`. На ширині від 320 px не має з’являтися горизонтальна прокрутка.
- Inter постачається разом із клієнтом як локальний variable font. Service worker додає до offline-оболонки кириличні та латинський піднабори; запити API до кешу оболонки не потрапляють.
