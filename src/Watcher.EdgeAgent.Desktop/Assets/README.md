# Тестові звуки

Файли `audio-test-tone.wav` і `audio-test-chime.wav` — короткі тихі PCM-зразки для ручної перевірки аудіопристрою у програвачі Windows і локальної кнопки «Перевірити навушники». Це синтетичні звуки, вони не імітують сигнал тривоги.

Локальний тест відтворює WAV у сеансі поточного користувача й перевіряє його типовий вихід. Він не підтверджує, що служба в Session 0 бачить цей вихід. Окремі кнопки тесту служби генерують короткий звук у Session 0; вони не передають WAV-файли службі й не створюють команду оповіщення.
