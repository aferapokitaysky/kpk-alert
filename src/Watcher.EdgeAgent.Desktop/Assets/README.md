# Тестові звуки

Файли `audio-test-tone.wav` і `audio-test-chime.wav` — короткі тихі PCM-зразки для ручної перевірки аудіопристрою у програвачі Windows. Це синтетичні звуки, вони не імітують сигнал тривоги.

Панель перевіряє вихід окремим фіксованим тестом служби в Session 0. Вона не передає WAV-файли службі й не створює команду оповіщення.
